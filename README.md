## Overview

DevPulse AI is a native Android application that analyzes a developer's GitHub profile and transforms repository activity into meaningful insights, skill analytics, and personalized growth recommendations.

Instead of displaying raw GitHub statistics, DevPulse AI aims to provide an AI-driven view of a developer's strengths, skill gaps, learning roadmap, and overall technical growth.

---

## Features (Current)

- GitHub Username Authentication
- GitHub Profile Fetching
- Developer Dashboard
- Repository Analytics
- Language Distribution
- AI Insights
- Personalized Growth Roadmap
- Material 3 Dark UI
- Modern Jetpack Compose Interface
